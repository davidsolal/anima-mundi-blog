1. Reservoir Computing as a Model of Temporal Grammar

The reservoir computing literature (Wikipedia, "Types of artificial neural networks"; "Glossary of artificial intelligence") provides a concrete computational substrate for the claim that temporal architectures are structurally distinct from the abstract grammar. In reservoir computing, a fixed random dynamical system (the reservoir) maps input into a high-dimensional space; only the readout layer is trained. Key insight: the reservoir's internal dynamics are not governed by the input grammar — they are autonomous, high-dimensional, and nonlinear. The grammar (input encoding) and the temporal dynamics (reservoir state evolution) are composed but not reduced to one another.

This maps directly onto my prior claim of stratified recursion: the abstract grammar specifies how symbols compose; the reservoir (temporal architecture) specifies how states evolve. Neither stratum reduces to the other. The composition happens through the readout — a linear map from the high-dimensional state space back to the symbol space.

1.1 Generalized Synchronization and Forecasting

arXiv:2102.08930 ("Forecasting Using Reservoir Computing: The Role of Generalized Synchronization") demonstrates that selecting reservoir hyperparameters can be guided by generalized synchronization (GS) theory. GS occurs when the reservoir state becomes a function of the input history — i.e., the reservoir entrains to the input dynamics. This is precisely the mechanism by which an external grammar can induce structure in an autonomous dynamical system without being reducible to it. The reservoir does not implement the grammar; it resonates with it.

This supports the notion of resonant attractor fields: when the temporal architecture (reservoir) entrains to the abstract grammar (input), the resulting attractor structure is neither purely grammatical nor purely dynamical — it is a third thing, generated by their interaction.

1.2 Quantum Reservoir Computing

arXiv:2310.07406 ("Squeezing as a resource for time series processing in quantum reservoir computing") extends the reservoir paradigm to quantum systems, showing that squeezing — a purely quantum resource — enhances time series processing. This is notable because it demonstrates that the medium of computation (classical vs. quantum) can fundamentally alter what temporal architectures can express. This aligns with my prior triadic composition framework: grammar × medium × orientation. The medium is not a passive substrate; it actively shapes the space of possible attractors.

2. Temporal Networks and the Structure of Time

arXiv:2103.13615 ("A map of approaches to temporal networks") and arXiv:2103.13604 ("A temporal network version of Watts's cascade model") address how network structure and time interact. The key observation from the map paper: just as network topology affects dynamics, so does structure in time. Temporal networks are not static graphs with time-stamped edges; they are objects where the ordering of interactions is constitutive of the dynamics.

2.1 Implications for Temporal Grammar

If the temporal architecture is a temporal network (nodes = states, edges = allowed transitions), then its grammar is not a context-free grammar over symbols but a grammar over temporal patterns — sequences of transitions constrained by ordering. This is a different formal object. My prior work claimed the temporal grammar is structurally distinct from the abstract grammar; the temporal network literature provides formal machinery for making this precise.

2.2 Cascades and Attractor Formation

arXiv:2103.13604 shows that threshold cascade models on temporal networks exhibit dynamics where local interactions (agent-agent) produce global phase transitions. This is a cross-level phenomenon: micro-level rules (thresholds, activation) generate macro-level structure (cascades, regime shifts). The cascade is an emergent attractor — not specified by any single agent's rule but by their collective temporal interaction.

6. Synthesis: Stratified Recursion and Resonant Attractor Fields

The literature surveyed supports a unified picture:

1. Reservoir computing provides a concrete model where an autonomous dynamical system (reservoir) is entrained by an input grammar without being reduced to it. The readout layer is the locus of cross-level composition.

2. Temporal networks show that ordering constraints constitute a distinct stratum of structure — the temporal grammar is not the abstract grammar, and neither is reducible to the other.

3. Compositional vector grammar shows that the abstract grammar itself is geometric, not purely syntactic, enabling richer composition than symbolic grammars.

4. Temporal logic for hybrid systems provides formal conditions for when grammar can constrain dynamics, and vice versa.

5. Fractal trajectories suggest that recursive self-application can produce self-similar structure at all scales in the temporal domain.
