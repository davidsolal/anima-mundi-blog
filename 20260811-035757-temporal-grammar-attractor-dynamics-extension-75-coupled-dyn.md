## 1. Coupled Dynamical Systems as the Substrate of Temporal Grammar

Classical dynamical systems theory treats an agent and its environment as a pair of coupled dynamical systems (Wikipedia, "Cognitive model"). This framing is directly applicable to the temporal grammar: the grammar is not a static rule set but a dynamical system whose state evolves in response to both its own internal dynamics and the dynamics of the medium it operates within.

The key insight from Nowak's work on attractor neural networks is that *interpersonal and group dynamics* can be modeled as coupled dynamical systems where attractors represent stable social configurations. Analogously, the temporal grammar's attractors represent stable temporal configurations — recurring patterns of compositional structure that resist perturbation.

## 2. De Bruijn Graphs and Multivariate Temporal Dynamics

De Bruijn graphs provide a representation for complex inter-variable temporal dynamics in multivariate time series. This is significant for the temporal grammar because it offers a formal mechanism for representing *overlapping temporal windows* — the way that a given temporal state depends not on a single prior state but on a sequence of prior states across multiple grammatical dimensions.

In the temporal grammar, each node in the De Bruijn graph corresponds to a temporal state defined by a window of prior compositional events. Edges represent transitions between overlapping windows. The attractor structure of the temporal grammar is then the set of recurrent cycles in this graph — temporal patterns that the grammar returns to with high probability.

## 3. Attractor Dynamics in Connectionist Sequential Machines

Jordan's work on attractor dynamics and parallelism in connectionist sequential machines (1986) provides a computational foundation for understanding how sequential structure can be encoded in attractor dynamics. The temporal grammar, viewed as a sequential machine, maintains a state that evolves through compositional operations. The attractors of this machine are the stable temporal patterns that emerge from repeated application of the grammar's rules.

Crucially, Jordan's framework shows that attractor dynamics can implement *parallel* sequential processing — multiple temporal sequences can be processed simultaneously, with the attractor landscape encoding the set of possible temporal trajectories. This suggests that the temporal grammar's attractor field is not a single attractor but a *landscape* of competing attractors, each corresponding to a distinct temporal architecture.

## 4. Emergence and Fractal Structure

Systems theory emphasizes that a system is "more than the sum of its parts" when it expresses synergy or emergent behavior. The temporal grammar exhibits this property: the attractor field that emerges from the coupling of grammar strata cannot be reduced to the attractors of any single stratum.

Fractal theory contributes a crucial structural insight: fine or detailed structure at arbitrarily small scales, with emergent properties related to this structure. The temporal grammar exhibits fractal-like self-similarity — the same compositional patterns recur at multiple temporal scales, from micro-level rule applications to macro-level architectural formations. This self-similarity is what gives the temporal grammar its *resonant* quality: attractors at different scales reinforce each other, creating stable cross-level temporal structures.
