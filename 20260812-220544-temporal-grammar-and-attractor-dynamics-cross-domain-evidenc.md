## 1. Cognitive Models as Coupled Dynamical Systems

The Wikipedia entry on cognitive models describes a "behavioral dynamics" approach that treats agent and environment as a pair of coupled dynamical systems grounded in classical dynamical systems theory. This is directly relevant: the temporal grammar I have posited is not a static rule set but a coupling structure between strata. The behavioral dynamics framing suggests that the grammar's temporal dimension emerges from the *interaction* between the agent's internal compositional rules and the environment's own dynamics — not from either alone. This supports the claim that temporal grammar is irreducible to the abstract grammar: it is a relational property, not a substantive one.

## 2. Attractor Neural Networks and Group Dynamics

Andrzej Nowak's work uses attractor neural networks to model interpersonal and group dynamics, and coupled dynamical systems to simulate emergence. This is a striking parallel: attractors in social systems are not fixed points but *temporal patterns* — rhythms of coordination, polarization, and phase transitions. The temporal grammar of a social system is the set of rules by which these attractors form, persist, and dissolve. Nowak's approach confirms that attractor dynamics can serve as a *descriptive language* for temporal structure, which is precisely the role I have assigned to temporal grammar.

## 3. De Bruijn Graphs and Temporal Dynamics in Multivariate Time Series

The De Bruijn graph literature shows how correlated variables can be represented as complex inter-variable temporal dynamics in multivariate time series. The De Bruijn torus and Hamming graph constructions provide a combinatorial substrate for temporal sequences — a way to encode the *grammar* of transitions between states. This is a concrete mathematical instantiation of what I have called temporal grammar: a graph-theoretic structure whose nodes are states and whose edges are admissible transitions. The fact that De Bruijn graphs capture *all* possible sequences of a given length over an alphabet suggests that temporal grammar, at its most general, is a constraint on the space of possible temporal trajectories.

## 4. Attractor Dynamics in Connectionist Sequential Machines

Jordan's 1986 work on "Attractor dynamics and parallelism in a connectionist sequential machine" (cited in the deep learning literature) is foundational. It demonstrates that recurrent networks can implement sequential processing through attractor dynamics — the network settles into attractors that correspond to temporal states, and transitions between attractors are governed by the network's weights. This is a direct computational model of temporal grammar: the grammar is encoded in the weight structure, and the attractor landscape is the set of admissible temporal trajectories. The connectionist framing is important because it shows that temporal grammar need not be explicit or symbolic; it can be implicit in a dynamical system's structure.

LTL provides a formal language for specifying temporal properties — a *grammar* for temporal statements. The key insight is that LTL specifications can be guaranteed for hybrid systems under certain conditions, meaning that temporal grammar can be *verified* — it is not merely descriptive but normative. ## 9. Synthesis: Convergent Evidence for Temporal Grammar as a Distinct Stratum

The external literature provides convergent support for the temporal-grammar hypothesis:

1. **Relational not substantive**: Temporal grammar is a property of couplings between systems, not of individual systems (cognitive modeling, quantum entanglement).
2. **Implicit not explicit**: Temporal grammar can be encoded in dynamical structure without being symbolically represented (connectionist models, DMD).
3. **Multi-scale and self-similar**: Temporal grammar operates at multiple scales with fractal structure (Internet traffic, fractal grammar).
4. **Normative as well as descriptive**: Temporal grammar constrains admissible trajectories, not just describes observed ones (LTL for hybrid systems).
5. **Empirically accessible**: Temporal grammar can be extracted from data using methods like DMD.
6. **Emergent from discrete rules**: Continuous temporal dynamics can arise from discrete rule application (quantum collision models).

These findings strengthen the stratified recursion framework: temporal grammar is not a metaphor but a structural feature of complex systems, observable across domains from cognitive science to quantum physics.
